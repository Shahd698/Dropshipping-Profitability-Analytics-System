# Dropshipping Profitability Analytics System

Excel-based profitability model for product testing and scaling decisions.

## Sheets
| Sheet | Purpose |
|-------|---------|
| Control Panel | Industry selector — drives all dynamic labels |
| Profit Calculator | Main P&L model with break-even & LTV analysis |
| Scenario Analysis | Side-by-side comparison of pricing scenarios |
| Executive Dashboard | KPI summary (Revenue, Net Profit, ROAS, Score) |
| Raw Data | 500 orders with auto-calculated cost & profit columns |
| Data Transformation | Enriched Raw Data with ROAS, Profit Tier, Month |
| Product Master | Product catalogue reference |

## How to Use
1. Open **Control Panel** → select your industry from the dropdown
2. Fill blue cells in **Profit Calculator** — these are your inputs
3. All black cells calculate automatically — do not edit them

## Industry Modes
- **Dropshipping** — Ad Spend, Product Cost, Shipping Cost
- **Retail** — Marketing Spend, COGS, Fulfillment Cost  
- **SaaS** — Growth Spend, Cost to Serve, Churn Rate
