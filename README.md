# Dropshipping Profitability Analytics System 

## Project Overview
This project is an advanced data analytics and profitability management system designed for E-commerce and Dropshipping business models. It processes transaction-level data, evaluates product-level margins, simulates multiple business scenarios, and summarizes performance indicators through an Executive Dashboard to support data-driven decisions.

## Tools and Techniques Used
- Advanced Excel Functions: Built automated pricing models and core unit economics logic.
- Power Query (ETL): Used for data cleaning, structural transformations, and maintaining data pipelines.
- Data Modeling: Managed relational logic between Product Masters and Raw Transaction Records.
- Scenario Analysis: Developed what-if analysis models to stress-test financial performance under shifting cost variables.
- Business Intelligence: Designed an Executive Dashboard for executive health tracking and performance visibility.

## Repository Structure and Core Components
1. Project Overview: Documentation of the analytics pipeline, project objectives, and operational guidelines.
2. Raw Data: Dataset containing 500 generated transaction-level e-commerce records, tracking dimensions such as Country, City, Channel, and Campaign.
3. Product Master: The central data repository defining individual Product IDs, Category classifications, Supplier assignments, and base unit economic profiles.
4. Profit Calculator: An interactive evaluation tool featuring automated logic to score and classify new potential product testing opportunities.
5. Scenario Analysis: Strategic business case testing evaluating a Base Case against multiple cost-variance models (Scenario A, B, and C) adjusting Ad Spends, Units Sold, and Shipping variables.
6. Executive Dashboard: A high-level dynamic command board aggregating metrics like Winning Product Scores, Campaign Safety Verdicts, Break-even ROAS, Break-even CAC, and overall Profit Margin percentages.

## Analytical Logic and Business Insights Delivered
- Product Decision Engine: Automated scoring algorithms that categorize product viability based on risk factors, current ROAS metrics, and profit margins.
- Campaign Performance Safeguards: Dynamic benchmarking that flags whether active advertising efforts are running above or below essential break-even thresholds.
- Financial Metrics: Implementations of crucial e-commerce health metrics, including Unit Contribution Margins, LTV to CAC ratios, and Net Profit Margin analysis.
